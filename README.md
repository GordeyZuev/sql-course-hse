## **О курсе**

Курс читается для студентов 1 курса магистратуры «Искусственный интеллект» в 1 модуле 2026/2027 учебного года в качестве «Семинара наставника».

Курс направлен на изучение языка SQL. Изучение представляет из себя набор теории и практик, позволяющих писать запросы к базам данных (БД) и использовать стандартные функции обработки данных.

### **Подробное описание пар**


#### **Пара 1 – «Введение» (05.09.2026)**

**Цель:** научиться читать данные из одной таблицы.

- Введение: зачем SQL в ИИ-проектах; таблица, столбец, строка.
- Операторы выборки: `SELECT`, `FROM`, `WHERE`, `ORDER BY`, `LIMIT`.
- Типы данных; `NULL` и `IS NULL`.
- Фильтрация: `AND` / `OR`, `IN`, `BETWEEN`, `LIKE`.

---



#### **Пара 2 – «Сжимаем и группируем» (10.09.2026)**

**Цель:** агрегировать данные и фильтровать группы.

- `GROUP BY`; агрегатные функции: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.
- `HAVING` vs `WHERE` – на простом примере.
- Простые подзапросы: scalar в `WHERE`, `IN (...)`.

---



#### **Пара 3 – «Склеиваем таблицы» (12.09.2026)**

**Цель:** объединять данные из нескольких таблиц.

- `INNER JOIN`, `LEFT JOIN` – когда какой использовать.
- CTE (`WITH ... AS`) – многошаговые запросы.
- `UNION ALL` – склеить два одинаковых по структуре `SELECT`.

---



#### **Пара 4 – «Анализируем и сохраняем» (17.09.2026)**

**Цель:** научиться применять оконные функции и сохранять результаты запросов в БД.

**Оконные функции:**

- `ROW_NUMBER`, `RANK`, `DENSE_RANK`.
- `SUM(...) OVER (PARTITION BY ... ORDER BY ...)`.
- `LAG` / `LEAD` – один пример, если успеваем.

**DML и DDL:**

- `INSERT ... SELECT`.
- `CREATE TABLE AS SELECT`.
- `UPDATE` / `DELETE` с `WHERE`.
- `BEGIN` / `COMMIT` / `ROLLBACK`.

### **Дедлайны**

- **Мягкий** – свой у каждого ДЗ. До этого момента балл считается без штрафа.
- **Жёсткий** – общий для всех четырёх ДЗ: **27.09.2026, 23:59 MSK**. После него работа не принимается.

Если сдали после мягкого, но до жёсткого, сырой балл умножается на штраф:

```text
late_hours = число полных часов опоздания; неполный час считается как целый
балл = округлить(сырой * 0.9 ** (late_hours / 24), 2)
```

Пример: опоздание на 24 часа даёт коэффициент `0.9`; на 48 часов – `0.81`.
